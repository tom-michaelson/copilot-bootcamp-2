# UI Guidelines

## TODO App Design Guidelines

This document outlines the user interface guidelines for the TODO application.

### Color Palette

- The color palette should be **vibrant** and engaging

### Task Status Colors

- **Past Due Tasks**: Background color should be **red**
- **Tasks Due Within 1 Day**: Background color should be **yellow**
- **Red or Yellow Task Text**: Foreground color should be **white** for readability

### Animations

- **Click Actions**: Should include fun animations to enhance user experience
  - Example: When a task is marked as complete, it should display a celebratory animation or visual effect
