# Functional Requirements

## TODO App Requirements

This document outlines the functional requirements for the TODO application.

### Task Properties

A task should have the following properties:
- **Description**: Text describing the task
- **Due Date**: When the task should be completed
- **Completed Flag**: Boolean indicating whether the task is complete

### Core Features

1. **View the list of tasks**
   - Users can see all tasks in their TODO list

2. **Create a new task**
   - Users can add new tasks to their list

3. **Edit the task**
   - Users can edit the description of a task
   - Users can edit the due date of a task

4. **Mark task as Complete**
   - Users can mark a task as completed
   - Users can only delete tasks once they are completed.

5. **Sort tasks**
   - Users can sort tasks in whatever order they would like
   - Sorting should be done in a drag and drop interface
